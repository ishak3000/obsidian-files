[[Отключение учетной записи пользователя]]
**useradd** - создает новых пользователей 
**groupadd** создает новые группы
**userdel** - удаляет пользователей 
**groupdel** - удаляет группы 
**usermod** - изменяет настройки существующего пользователя 
**passwd** - создает и изменяет пароли


**Определение UID и GID пользователя**

**Реальный идентификатор** - это UID и GID основной группы, присвоенные пользователю при создании. Это то что вы видите, когда запускаете команду id без параметров от своего имени 

**Эффективный идентификатор** - это UID, используемый для запуска процесса, которому требуются привилегии, отличные от привилегий пользователя, запускающего процесс
(показывает чьи права программа использует прямо сейчас)

**Сохраненный идентификатор** - нужен для того, чтобы программа могла временно отказаться от прав root, побыть обычными пользователем ради безопасности, а затем снова вернуть себе права root, когда это понадобится 

**sudo passwd -e test1** - заставляет пользователя сменить пароль при первом входе в систему, после того как вы создали пароль

**sudo useradd -mU test2**
параметр -m позволит создать домашний каталог пользователя, а параметр -U личную группу с именем, совпадающим с именем пользователя 

**sudo useradd -rs /bin/false service1** - создает системного пользователя без домашнего каталога, без оболочки входа и с UID из диапазона, предназначенного для системный пользователей 

параметр -r создает системного пользователя с реальным UID из диапазона, предназначенного для системных пользователей 

параметр -s задает оболочку входа /bin/false - команду, которая ничего не делает и не позволяет выполнить вход в систему с именем этого пользователя 

**ДЛЯ ubuntu, debian и других производных от Debian**
Настройки по умолчанию для adduser определены в файле **/etc/adduser.conf**
в том числе:
**DSHELL=** - оболочка входа по умолчанию 
**USERGROUPS=yes** - создает личную группу для каждого нового пользователя 
**EXTRA_GROUPS=** - список дополнительных групп для новых пользователей 

**sudo adduser   - - system   - - no-create-home   - - group service1**
эта команда создаст системного пользователя без домашнего каталога и с собственной основной личной группой 


**sudo addgroup composers** - пример команды для создания группы пользователей-людей 

**suso addgroup  - - system service1** - команда создаст системную группу 

**sudo userdel -r** - удаляет пользователя и его домашний каталог

**sudo delgroup** - удаляет группу. Данная команда не удаляет основную группу, если в нее включен существующий пользователь

Если нежелательно удалять непустые группы, то добавьте в команду параметр 
**- - only-if-empty**
**sudo delgroup - - only-if-empty**


**su -l** - команда для получения привилегии root
параметр -l настраивает среду выполнения и выполняет переход в домашний каталог пользователя root

Чтобы включить пользователя в группу используется команда usermod 

например:
**sudo usermod -aG musicians duchess**

чтобы добавить в несколько групп, просто перечислите их через запятую.

**Альтернативное решение** - просто отредактировать файл /etc/group и добавить имя пользователя по все группы, в которые он должен входить 

**ЕСЛИ вы забудете параметр -а и укажете только -G, то все пользователи, прежде входившие в группу, будут исключены из нее**

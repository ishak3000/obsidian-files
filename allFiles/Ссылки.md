#linux

При создании файла ему выделяется место на диске, а его имени сопоставляются ссылка из каталога на участок диска, где физически находится файл. таким образом можно создать несколько ссылок на одни и те же данные 

команда ls -il - выводит дескриптор файла, который определяет его физическое расположение 

**Жесткие ссылки**
жесткая ссылка указывает непосредственно на данные и имеет тот же дескриптор. такой файл физически не удаляется из системы, пока не будут уничтожены все жесткие ссылки на него 

ln «имя файла» «имя ссылки» - создает жесткую ссылку на файл

**Символьные ссылки**
символьная ссылка указывает не на данные, а на имя файла.

ln -s «имя файла» «имя ссылки» - создает символьную ссылку на файл

если удалить корневой файл, то ссылка будет «битая», то есть указывать на несуществующий файл.

если записать какие либо данные в ссылочный файл, то корневой автоматически создастся

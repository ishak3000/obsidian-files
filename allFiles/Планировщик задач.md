[[Процессы]]

Проблема решается через использование программы cron. для этого должен быть установлен демон crond
Для работы с демоном crond используется программа crontab 

00 5 * * * команда - шаблон для создания задачи
**минуты часы день месяц деньнедели команда**

День недели указывается числом от 0 до 7

Чтобы просмотреть список существующих заданий, выполните команду crontab -l. 
Для редактирования уже созданных записей выполните команду crontab с параметром -e

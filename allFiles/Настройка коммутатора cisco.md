переход в привилегированный режим EXEC - **enable**
переход в режим глобальной конфигурации- **configure** **terminal**
задание имени устройства - **hostname** “name”
задание пароля для доступа к прив. режиму - **enable secret “password”**
переход в режим конфигурации консоли - **line console 0**
задание пароля для консольного подключения - **password “password”**
включение режима входа по паролю - **login**
задание баннера - **banner motd !message!**
включение шифрования паролей - **service password-encryption**


**startup-config** - это сохраненный файл конфигурации, который хранится в NVRAM. он содержит все команды, которые будут использоваться при загрузке или перезагрузке. 
**running-config** - это файл текущей конфигурации, хранится в RAM. 

Чтобы сохранить изменения текущей конфигурации в файле загрузочной конфигурации(startup config) используется команда прив-го режима EXEC copy running-config startup-config

Загрузочную конфигурацию можно удалить с помощью команды прив-го режима EXEC - **erase startup-config**

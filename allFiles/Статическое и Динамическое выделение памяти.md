#cpp

**Динамическая память** - это область оперативной памяти, размер которой программа может выделять и освобождать прямо во время своей работы

Динамическая память требуется в случае, если заранее неизвестно сколько памяти будет затрачено 

**Указатель** -  хранит адрес ячейки памяти, где хранятся данные

**Heap(куча)** - специальная область памяти, выделяемая для хранения динамических данных и объектов, к которым можно обращаться из разных областей программы.
Управление кучей происходит в ручную, то есть вручную выделяется и удаляется память
куча не является структурированной, данные разбросаны в случайном порядке по всей доступной памяти

#Linux 
Допустим, нужно задать для другого пользователя другое время кэширования пароля, отличное от вашего

Отдельные конфигурации можно создавать в /etc/sudoers.d 
Например: 
cd /etc/sudoers.d/
sudo visudo -f stash
После этого необходимо ввести в файле
**Defaults timestamp_timeout=30**
и сохранить файл. После этого вы увидите новый файл:
sudo ls /etc/sudoers.d
README stash

В файлы отдельных конфигураций нужно вводить только настройки, **отличающиеся от настроек в /etc/sudoers**


**Чтобы настроить команду sudo для запроса собственных паролей пользователей** отредактируйте файл /etc/sudoers, законспектировав следующие две строки:
**Defaults targetpw**
**ALL ALL=(ALL) ALL**

В openSUSE и Fedora создайте пользователей audi с неограниченными привилегиями root, добавив из в группу wheel в файле /etc/group

[[Процессы]]

задание можно сформировать с помощью команды **at**
at hh:mm dd.mm.yy

**Например**
необходимо в определенное время удалить пользователя

**at 12:50** 
В ответ появится приглашение для ввода команд: **at>**

userdel tempuser
rm -rf /home/tempuser

С помощью команды **atq** можно увидеть список заданий, поставленных в очередь


Временно деактивировать учетную запись можно, выключив пароль с помощью команды passwd:
**sudo passwd -l stash**
теперь пользователь не сможет войти

следующая команда разблокирует учетную запись 
**sudo passwd -u stash**
Однако этот способ не помешает пользователю аутентифицироваться иным способом, например с помощью ключа SSH. Для модного отключения учебной записи примените команду usermod:

**sudo usermod   - - expiredate 1 stash** 
Когда пользователь попытается войти, они увидит сообщение **Your account has expire; please contact your system administrators**

Чтобы восстановить учетную запись, выполните команд:
**sudo usermod   - - expiredate -1 stash**

Еще один способ отключить учебную запись - **заменить х в поле пароля в файле /etc/passwd звездочкой**
